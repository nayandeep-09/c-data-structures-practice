<!-- ===================== RUN ===================== -->
<h2>▶️ How to Run the Programs</h2>

<ol>
  <li>Install <b>GCC Compiler</b></li>
  <li>Compile the program:
    <pre>gcc filename.c -o output</pre>
  </li>
  <li>Run the program:
    <pre>./output</pre>
  </li>
</ol>

<p><b>Windows users:</b> run <code>output.exe</code></p>
